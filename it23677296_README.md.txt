##  How to Run the Project

1. Open terminal inside project folder  

2. (Optional) Activate virtual environment  
   venv\Scripts\activate  

3. Install dependencies  
   pip install -r requirements.txt  
   playwright install  

4. Run the automation script  
 python test_automation.py --excel "C:\Users\ayesh\OneDrive\Desktop\Y3 S1\ITPM\IT23677296\Assignment 1 - Test cases.xlsx" --url "https://www.pixelssuite.com/chat-translator" --wait-ms 20000 --type-delay-ms 150 --slow-mo-ms 800 --save-every 1 --keep-open---
